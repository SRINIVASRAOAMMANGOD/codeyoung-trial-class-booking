# Codeyoung Trial Class Booking — Frontend

This is the React + Vite frontend for the Codeyoung Trial Class Booking System.

For full project documentation, setup instructions, and architecture details,
see the root [README.md](../README.md).

## Development

```bash
cp .env.example .env.local   # set VITE_API_BASE_URL if needed
npm install
npm run dev                  # starts dev server on http://localhost:5173
```
